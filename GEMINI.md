# nmr-walkthrough

When the user asks to explain or solve an NMR spectrum or structure problem, use the `nmr-step-walkthrough` skill and the `nmr_walkthrough_guide`, `validate_nmr_walkthrough` and `build_nmr_walkthrough` tools.

Ground rule: every shift, J value and cross peak must come from the user's own spectra or peak list, or from a cited measured source. Never fill in numbers from memory. If no real data is available, ask the user for it.
